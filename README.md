# Tails ’n’ Elegance Café — Stage 1 Website

A separate static website for the Tails ’n’ Elegance Café brand, designed for hosting on GitHub Pages.

## Contents

- `index.html` — semantic, accessible, responsive one-page brand website.
- `styles.css` — original olive, wine, peach, and cream identity inspired by the supplied logo.
- `script.js` — responsive mobile navigation; no JavaScript dependencies.
- `assets/tails-n-elegance-logo.webp` — optimized image derived from the supplied brand logo (original appearance preserved).

## Stage 1 decisions

- Current menu is a **category preview**, not a confirmed list of products or prices.
- Address, opening hours, and contact details have deliberately **not** been invented.
- No payments, reservations, forms, or booking links are simulated.
- To publish independently from ODDY, create a new empty public repository under `Jenu11`, then upload these files (GitHub Pages: deploy from the default branch root). The ODDY repository is untouched.

The site works locally by opening `index.html`. Google Fonts are optional; the website has system-font fallbacks.

## Deployment

This site's homepage is `index.html` at the root of `main`. To publish it, open **Settings → Pages**, select **Deploy from a branch**, choose **main / (root)**, then save. After GitHub Pages finishes deploying, visit https://jenu11.github.io/tails-n-elegance-cafe/.
